# Choix du modèle dans un chat Codex

La montre propose le choix du modèle et du niveau de réflexion directement dans un chat Codex. Une sélection propre à ce chat est enregistrée séparément du réglage général et des autres conversations. « Réglage général » rétablit l’héritage ; « Du PC » permet d’utiliser explicitement les réglages du chat sur le PC. Le choix est transmis pour les demandes suivantes et lorsqu’un Live est lancé sur ce chat ; il ne change pas une génération déjà démarrée.

La liste des modèles et réflexions provient du relais et les choix sont validés avant transmission. L’interface du PC ne fournit pas ces réglages pour les conversations ChatGPT : la montre indique que le choix se fait sur le PC. Les tests vérifient les choix explicites, l’héritage et l’isolation par chat et par relais. Sur la montre, le bouton en bas du chat, les modèles et les niveaux de réflexion ont été contrôlés ; le réglage général initial a été rétabli après l’essai, sans envoyer de message. La version finale 0.12.23 a été installée et son APK vérifié ; les 51 tests de la montre et le contrôle lint passent. La transmission réelle d’une nouvelle demande avec un choix personnalisé reste à vérifier lors de l’utilisation.
