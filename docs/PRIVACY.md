# Confidentialité — Codex Watch

Codex Watch est un logiciel indépendant, sans affiliation avec OpenAI. Le propriétaire du relais choisit les projets et services connectés. Aucun service central Codex Watch ne collecte les données de l’application.

La montre transmet les demandes et reçoit les réponses par HTTPS ou par Bluetooth chiffré auprès du relais choisi. Le relais conserve localement les reçus d’envoi, des extraits de conversations, les événements et, si activées, les inscriptions aux notifications. Les conversations natives restent dans Codex ou ChatGPT selon le contexte. Le Chat utilisant l’API sur un VPS possède un historique distinct, stocké dans les données de ce relais. Les demandes sont traitées par les services correspondants et leurs propres conditions s’appliquent.

Le microphone n’est utilisé qu’après le démarrage explicite du Live, avec l’autorisation Android. Le Live envoie le flux audio au relais puis à l’API OpenAI ; transcription et synthèse sont traitées par ce service. Le relais ne sauvegarde pas le flux microphone. Il conserve des compteurs techniques, notamment le nombre de signaux d’activité sonore détectés par la montre, pour faciliter le diagnostic. Les transcriptions et réponses vocales sont conservées localement dans un journal lié au chat, limité aux 30 derniers appels, à 120 segments par appel et à 12 000 caractères par segment. Les demandes transmises entrent aussi dans le chat natif concerné. Le relais garde un instantané des messages visibles des dix derniers chats ChatGPT consultés pour les périodes de limitation du service. En quittant l’écran, l’enregistrement s’arrête. La dictée système dépend du moteur vocal choisi dans les paramètres de la montre.

La lecture OpenAI envoie le texte des réponses à l’API. Les fichiers vocaux générés sont mis en cache sur le relais, dans une limite de 128 fichiers et 64 Mio. Les compteurs audio stockent des estimations de dépenses et des provisions. La clé API reste sur le relais choisi : l’interface Windows la chiffre avec le coffre système ; sur un VPS, elle est conservée dans un fichier accessible au compte du relais et peut être affichée par un administrateur connecté. La montre conserve son jeton de relais dans un stockage chiffré et ne contient pas la clé OpenAI. La lecture Phonon utilise le modèle installé sur le relais et ne transmet pas le texte à l’API OpenAI.

Si le relais a été configuré pour Firebase Cloud Messaging, Google traite les jetons de notification et les titres/extraits nécessaires à leur livraison. Sans FCM, le mode direct entretient une connexion au relais et peut consommer davantage de batterie. Aucun suivi publicitaire ni outil d’analyse d’audience n’est intégré.

La découverte Wi-Fi publie uniquement l’adresse HTTPS du relais. L’association exige un code temporaire affiché dans le relais PC ou dans l’administration web du VPS. Le transport HTTPS peut être fourni par Tailscale ou un autre opérateur choisi par le propriétaire ; leurs politiques s’appliquent également.

Pour retirer la connexion de la montre : Paramètres → Connexions → Modifier → Oublier. Pour supprimer les données du relais, arrêter le relais puis supprimer son dossier de données depuis le système d’exploitation. L’application Windows conserve les données lors de sa désinstallation afin d’éviter une perte involontaire. Les données de compte présentes chez OpenAI ou Google se gèrent auprès de ces services.

Avant publication sur un store, l’éditeur doit publier cette politique sur une URL stable, ajouter son identité et un contact effectif, et vérifier les déclarations de sécurité des données pour le déploiement distribué. Ce document décrit le fonctionnement logiciel ; il ne constitue pas une déclaration déjà publiée au store.

En mode Bluetooth, la montre découvre les appareils à proximité après autorisation Android. Le relais PC annonce un service Bluetooth ; la liaison exige une association et un chiffrement Bluetooth ainsi que le jeton privé Codex Watch. La montre enregistre localement l’adresse du PC choisi. Les services en ligne passent par la connexion Internet du PC.

Lors d’une brève reconnexion du Live, le relais conserve temporairement en mémoire les événements et l’audio de réponse en attente ; ce tampon est effacé à la reprise ou à la fin de l’appel. Le microphone est en pause pendant la reconnexion.
