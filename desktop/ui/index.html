Connexion locale

Active le service, puis ouvre les paramètres Bluetooth de Windows sur « Ajouter un appareil ». Sur la montre, ouvre Codex Watch → Paramètres → Connexions → Réseau et cherche ce PC. Accepte l’association sur les deux appareils.

Sur la montre, choisis Automatique, Bluetooth ou Internet. Elle affiche les liaisons disponibles et la dernière utilisée.

La liaison Bluetooth est chiffrée et exige l’association Codex Watch existante. Le PC doit rester allumé et connecté à Internet pour les services en ligne.

Calcul sur ce relais

Le préchargement conserve le modèle en mémoire et utilise les ressources du PC dès le démarrage.

Le GPU utilise WebGPU sur les appareils compatibles. Si le GPU est indisponible, le relais revient au CPU. Le maintien en mémoire utilise davantage de RAM ou de mémoire vidéo.
